# Long Distance Date Night Activity Hub 📱✨

A lightweight, browser-based collection of interactive mini-games and conversation starters designed to bring fun, spontaneity, and connection to long-distance relationship (LDR) FaceTime and video calls.

Built purely with clean web standards, it runs instantly in any browser with zero installation or setup required.

---

## 🎮 Included Activities & Games

* **🎲 Homepage (`homepage.html`):** Central dashboard to browse and launch all available games and question decks.
* **❓ So Many Questions (`So-Many-Questions.html`):** A deep-dive question prompt generator designed to spark meaningful discussions, uncover new stories, and skip the small talk.
* **🤔 Would You Rather (`wouldyourather.html`):** Hilarious, tough, and thought-provoking scenarios to debate over video chat.
* **📖 Storytime (`storytime.html`):** Prompts and narrative-driven games to reminisce about past memories or build fun fictional scenarios together.
* **⭕ Tic-Tac-Toe (`tictactoe.html`):** Classic interactive two-player game to play in real time while on a call.

---

## 🛠️ Built With

* **HTML5:** Semantic game markup and multi-page routing
* **CSS3:** Responsive layout designed for desktop and mobile screens
* **JavaScript:** Dynamic question cycling, interactive turn mechanics, and client-side game state logic
